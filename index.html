      Help

      TrainFrame turns plain-text .frame files into interactive walkthroughs: problems revealed one step at a time, formula tags that open the formula where you are, and plots with sliders.

      Classes and tabs

      • Library lists every class. Click one and it opens as a tab next to Library. Close a tab with its × (or a middle click); the class stays in the Library.
      • Each class tab remembers its section and folder. The files you open get tabs in a row under the top bar, and each one remembers where you scrolled.
      • Edit class renames, archives or deletes a class. Renaming only changes TrainFrame: files whose class: line has the old name keep landing in the renamed class. Archived classes move to the bottom of the Library.

      Your files

      • Add files: drop .frame files anywhere on the page, pick them, or paste the text in. They stay in this browser.
      • Folders: a file's class: line picks its class and its folder: line picks the folder (folder: Exams/Midterm 1 makes a subfolder). Move on a file card files it somewhere else. That's saved in TrainFrame, and the file itself isn't changed.
      • Same file again: adding a file whose @frame id you already have asks before replacing it. Your notes and the place you filed it are kept.

      An open file

      • Problem rail on the left: jump to the formulas or to any problem. The one you're reading is highlighted.
      • Notes on the right edge: one box per file, saved as you type. Insert heading adds the problem you're on, and Export saves the notes as a Markdown file.
      • Formulas on the right edge: the file’s formula bank, next to your notes.
      • Calc on the right edge: a calculator window you can drag anywhere, on every screen.
      • Load report under the title: anything wrong in the file, with line numbers. Copy report for AI copies it so you can paste it back to whatever wrote the file.

      Writing a file

      A frame file is a list of blocks, each starting with an @ line:

      @frame {my-hw3}
title: Homework 3
class: ECEN 305
folder: Homework

@problem {P1} Find the constant
points: 8

@step Normalize {{F1}}
$$ \int_0^2 c\,x^2\,dx = 1 $$

      To have an AI write one, use Copy AI prompt and paste the result into the AI with the assignment attached. The prompt holds the instructions and the syntax guide (docs/SYNTAX.md). Inside a class, it fills in that class and folder. The full language is in docs/LANGUAGE.md.

      What's new

      0.5.0 (2026-11-02)
      Visuals are live: plots, stem plots, phasor diagrams, tables and calculators, with sliders, toggles and view buttons (like Part 1, Part 2, Explore). Captions and readouts update as you move a slider.
      0.4.0 (2026-11-02)
      Copy AI prompt (in Add files and here in Help) copies instructions and a syntax guide to paste into an AI with an assignment. Load-report items can be dismissed, per file. The warning for answers without a check is off unless you turn it on in Settings.
      0.3.0 (2026-11-02)
      Files open as walkthroughs: the formula bank with rendered math, each problem with its given, parts and steps (Next step, Show all, Hide), answers with a mark for checks that pass, formula tags that open the formula where you are, callouts and checklists. Your place in each stepper is remembered. Plots and other visuals are placeholders until the next version. The file's source is in a Source box at the bottom.
      0.2.0 (2026-11-02)
      Files are checked when they load. Every check: line is worked out, and a load report on the file lists errors and warnings with their line numbers. Click one to jump to it, or use Copy report for AI to send it back to whatever wrote the file. File cards and the Add files report show the result too. Open files share one row of tabs, and the formula bank and the calculator sit on the right edge with your notes.
      0.1.0 (2026-11-02)
      The working shell: the Library of classes, class and file tabs that remember where you were, folders, a class editor (rename, archive, delete), adding files, the problem rail, the notes box and the calculator window. A file opens as its source until the renderer is built. The calculator's keys come in a later version.
